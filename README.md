# Masjid Al-Hanna 🕌🌷

Website display masjid aesthetic dengan tema **Cute Pink & Cream**.

## Jalankan di GitHub Pages
1. Upload `index.html` ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih branch `main` dan folder `/ (root)`.
4. Simpan, lalu buka URL GitHub Pages yang diberikan.

Semua desain dibuat dalam satu file HTML sehingga mudah di-upload.
